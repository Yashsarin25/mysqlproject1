# MySQL Sales Analysis Project

## Project Overview
This project uses MySQL to analyze sales, orders, and customer data to answer business-related questions and derive actionable insights.

## Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## Dataset
The project uses three datasets:
- **Sales** — sales transaction data
- **Orders** — order-related information
- **Customers** — customer information

## Project Objectives
- Explore and understand the datasets.
- Clean and prepare data for analysis.
- Answer business questions using SQL queries.
- Identify patterns and trends in sales and customer data.
- Support data-driven business decisions.

## SQL Analysis
The project includes SQL scripts covering dataset exploration, data cleaning, and business analysis.

## Repository Structure
- `analysis1.sql` – Business analysis queries
- `analysis2.sql` – Business analysis queries
- Additional SQL scripts for analysis and data cleaning.
